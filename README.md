# Ansh Tomar - Personal Portfolio

A modern, responsive personal portfolio web application built with React, Styled Components, BaseUI, and Material Design elements.

## 🚀 Live Demo
Visit the portfolio at: [https://anshtomar-18.github.io](https://anshtomar-18.github.io)

---

## 🛠️ Tech Stack
- **Frontend**: React.js, Styled Components, Styletron, BaseUI, CSS3, HTML5
- **Animations**: React Reveal, Anime.js
- **Icons**: FontAwesome 6, SimpleIcons, Iconify
- **Deployment**: GitHub Pages / Netlify

---

## 📂 Project Structure
```
portfolio/
├── public/                # Static assets, HTML shell, and manifest
├── src/
│   ├── assets/            # Resume PDF, custom vector graphics, fonts
│   ├── components/        # Reusable UI components (Header, Footer, Cards)
│   ├── containers/        # Major page layout sections (Skills, Greeting, etc.)
│   ├── pages/             # Route views (Home, Education, Experience, Projects, Contact, Resume)
│   ├── shared/            # Project showcase data
│   ├── portfolio.js       # Central data file containing all profile information
│   └── theme.js           # Theme and styling definitions
```

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/anshtomar-18/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Start the local development server:**
   ```bash
   npm start
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
